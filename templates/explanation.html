Explainable AI & SHAP Attribution Framework

Demystifying gradient boosting predictions through game-theoretic Shapley additive explanations.

Why Explainability is Essential in Healthcare Machine Learning

Black-box machine learning models pose severe risks in clinical settings. Physicians, discharge planners, and quality officers cannot trust an uninterpretable probability score.

In this project, we employ TreeSHAP (Lundberg et al., 2020), which computes exact Shapley values derived from cooperative game theory. Every feature's contribution $\phi_i$ satisfies local accuracy (additivity):

Model Output (Log-Odds Margin) = Base Value (φ0 = -2.057) + ∑ φi(Featurei)

This guarantees mathematical consistency: the sum of feature attributions plus the baseline cohort rate exactly reconstructs the model prediction without heuristic approximations.

Core SHAP Properties
  • Additive Efficiency: Sum of attributions equals model margin.
  • Symmetry: Equal contributors receive equal importance.
  • Null Player: Unused features receive zero SHAP value.
  • Directionality: Clear distinction between risk factors and protective factors.
Global Feature Importance (Mean Absolute SHAP)
Interpretation: Ranked by mean absolute contribution across the cohort. Prior inpatient hospitalizations (`number_inpatient`) is the dominant factor, followed by discharge disposition, length of stay, and total medications.
SHAP Beeswarm Summary Plot (Impact & Direction)
Interpretation: Each dot represents an encounter. Red indicates high feature values; blue indicates low feature values. High prior inpatient visits (red) shift SHAP values strongly to the right (higher readmission risk).
Dependence: Prior Inpatient Stays vs Risk
